# Aurum — Premium Service Website Template

A luxury, conversion-focused website template for high-end service businesses. Built for salons, spas, consulting firms, restaurants, and professional services.

![Aurum Preview](https://velocity-portfolio.vercel.app/assets/hero-BEdLDUuh.jpg)

**Live Demo:** [velocity-portfolio.vercel.app](https://velocity-portfolio.vercel.app)

---

## ✨ Features

- **Premium Design** - Dark luxury aesthetic with gold accents
- **Fully Responsive** - Mobile, tablet, and desktop optimized
- **Fast Loading** - Optimized images and minimal code
- **Easy Customization** - Simple HTML/CSS edits for quick client deployments
- **Contact Forms** - Built-in form validation and submission handling
- **Gallery Section** - Showcase your best work with masonry layout
- **Testimonials** - Social proof carousel for client reviews
- **SEO Ready** - Meta tags, schema markup, and structured data
- **No Backend Needed** - Pure static HTML/CSS/JavaScript
